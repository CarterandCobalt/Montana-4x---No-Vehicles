MONTANA 4X — CARTER & COBALT EDIT
VERSION 2.0

IMPORTANT — DEALER VEHICLE HIDER / DISPLAY LOCK

Install and enable FS25_Dealer_Display_Lock_v1_4.zip for the intended dealership display behavior.
In the mod selection screen, it is named "Dealer Display Hotspot Hider & Showroom Lock."

This separate mod hides the dealership display equipment's map icons and prevents players from entering the display vehicles or attaching the display implements. The equipment remains visible at the dealership.
Player-owned and leased equipment, along with trains, are excluded from the display lock.
Without this mod enabled, the display restrictions and icon hiding will not be applied.

Place FS25_Dealer_Display_Lock_v1_4.zip in your FarmingSimulator2025/mods folder and enable it when starting or loading your Montana save. Leave the ZIP compressed. Remove older versions of the dealer hotspot hider or display lock before installing this version.

ABOUT THIS MAP

Montana 4X is a fictional Montana farming map originally created by DJ Modding.
Version 2.0 is the Carter & Cobalt edit, with rebuilt fields, revised farmland, updated farms, production balancing, improved access routes, and refreshed map visuals.

INSTALLATION

Place FS25_Montana_4X.zip in your FarmingSimulator2025/mods folder. Leave the ZIP compressed and keep its filename unchanged.
Keep only one active copy of the map in the mods folder. Move older versions and backups outside that folder.
Enable the map and the separate Dealer Display Hotspot Hider & Showroom Lock mod when creating your save.

A new save is recommended for Version 2.0 because the fields, farmland layout, starting farm, starting equipment, and default placeables have changed. Compatibility with saves from earlier map versions is not guaranteed.

FARM BUILDING AND ANIMAL PEN REMOVAL

Animal pens can be sold. After selling a pen, use Map Object Hider or Easy Development Tools to remove the remaining structures.
Original farm buildings can also be removed using Map Object Hider or Easy Development Tools.
These are separate tools and are only needed if you want to remove the original structures.
Placement restrictions have been removed so replacement buildings can be placed where the originals stood.

Removed separate land purchases between neighboring fields where no road divides them.
Expanded ownership boundaries around fields to make working near field edges easier.
Updated farmland prices based on field size and soil quality.
Relocated trees near fields to improve equipment clearance.

Adjusted multiple AI triggers.

Adjusted traffic paths and railroad crossings.
Removed parked cars that interfered with AI.
Added access paths around the map.
Removed collisions from roadside objects.

Lowered bridges slightly below road surfaces to separate overlapping collision meshes.
